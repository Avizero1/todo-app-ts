УЧАСТНИК 2 - БЭКЕНД НА KOTLIN

Проект: todo-приложение (фронт на TypeScript + бэк на Kotlin + база PostgreSQL).
Твоя часть: папка backend/ - сборка, подключение к базе, таблицы, модуль задач.

Ссылка на репозиторий: https://github.com/dodry-question/todo-app-ts

4. ОТКРЫТЬ БЭК В INTELLIJ
---------------------------------------------------------
IntelliJ -> Open -> выбрать папку backend (внутри todo-app-ts).
Первый запуск будет долгим: Gradle сам скачает всё, что прописано в build.gradle.kts.

Что Gradle должен скачать за тебя (это ты сам вписываешь в build.gradle.kts,
версии бери свежие):
   - движок Ktor: ktor-server-netty
   - JSON: ktor-server-content-negotiation, ktor-serialization-jackson
   - авторизация по токену: ktor-server-auth, ktor-server-auth-jwt
   - CORS и ошибки: ktor-server-cors, ktor-server-status-pages
   - логи: ktor-server-call-logging, logback-classic
   - база: exposed-core, exposed-jdbc, exposed-java-time, postgresql, HikariCP
   - хеш пароля: at.favre.lib:bcrypt (или org.mindrot:jbcrypt)
   - плагин Gradle application для запуска приложения

---------------------------------------------------------
5. ЗАПУСТИТЬ БЭК
---------------------------------------------------------
В IntelliJ: открой backend/src/main/kotlin/com/todo/Application.kt и нажми Run.
В терминале из папки backend: gradle run (если Gradle стоит отдельно).

Если нужна база только у себя, подними её в Docker:
   docker run --name todo-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=todo -p 5432:5432 -d postgres:16
