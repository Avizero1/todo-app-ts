=========================================================
УЧАСТНИК 5 - DOCKER И POSTGRESQL
=========================================================
Проект: todo-приложение (фронт на TypeScript + бэк на Kotlin + база PostgreSQL).
Твоя часть: docker-compose.yml, .env.example, backend/Dockerfile, frontend/Dockerfile,
frontend/nginx.conf, README.md.
Языки программирования тебе не нужны - только конфиги и команды.

Ссылка на репозиторий: https://github.com/dodry-question/todo-app-ts

---------------------------------------------------------
1. ЧТО СКАЧАТЬ
---------------------------------------------------------
1) Docker Desktop .......... https://www.docker.com/products/docker-desktop
   При установке включи WSL 2, после установки перезагрузи компьютер
   и запусти Docker Desktop (он должен работать, пока ты занимаешься проектом).
2) Git ..................... https://git-scm.com/download/win
3) Редактор для yml-файлов (например, VS Code) ... https://code.visualstudio.com
4) По желанию: DBeaver ..... https://dbeaver.io  (посмотреть таблицы в базе глазами)

PostgreSQL отдельно ставить НЕ нужно - он будет контейнером.

---------------------------------------------------------
2. ПРОВЕРИТЬ, ЧТО ВСЁ ВСТАЛО
---------------------------------------------------------
   docker -v
   docker compose version

Обе команды должны показать версию. Если пишет "не найден" - Docker Desktop не запущен.

---------------------------------------------------------
3. ЗАБРАТЬ ПРОЕКТ
---------------------------------------------------------
   git clone https://github.com/dodry-question/todo-app-ts
   cd todo-app-ts
   git checkout -b docker-team
   Copy-Item .env.example .env

Файл .env создаётся из шаблона .env.example, и в нём ты прописываешь свои значения
(пароль базы, порты, секрет токена). .env в git не попадает - там секреты.

---------------------------------------------------------
4. КОМАНДЫ, КОТОРЫЕ ПРИГОДЯТСЯ
---------------------------------------------------------
   docker compose up --build        собрать образы и запустить всё
   docker compose up -d             запустить в фоне (без логов в окне)
   docker compose logs -f           смотреть логи всех сервисов
   docker compose logs -f backend   смотреть логи только бэкенда
   docker compose ps                что сейчас запущено и на каких портах
   docker compose down              остановить всё
   docker compose down -v           остановить и удалить данные базы (начать с нуля)
   docker compose exec db psql -U postgres -d todo -c "\dt"     посмотреть таблицы в базе
   (имя пользователя и базы подставь свои из .env)

---------------------------------------------------------
5. ЧТО ДОЛЖНО ПОЛУЧИТЬСЯ
---------------------------------------------------------
Одна команда "docker compose up --build" поднимает три контейнера: фронт, бэк, база.
Фронт открывается в браузере по адресу из твоего .env, бэк отвечает по своему порту.

---------------------------------------------------------
6. ТВОИ ФАЙЛЫ (только их и правишь)
---------------------------------------------------------
   docker-compose.yml
   .env.example
   backend/Dockerfile, backend/.dockerignore
   frontend/Dockerfile, frontend/nginx.conf, frontend/.dockerignore
   README.md

Полный список задач с галочками: файл docs/plan.md, раздел "Участник 5".
Итоговый чек-лист "всё запускается" в конце docs/plan.md - это твоя проверка перед сдачей.

---------------------------------------------------------
7. ВАЖНО
---------------------------------------------------------
- .env в репозиторий не заливаем, только .env.example.
- Если образ бэкенда не собирается - зови участника 2, если фронта - участника 1 или 4.
- Проверь запуск "с нуля": docker compose down -v, потом docker compose up --build
  и убедись, что всё поднялось само, без ручных действий.
