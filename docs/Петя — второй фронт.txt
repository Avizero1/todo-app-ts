=========================================================
УЧАСТНИК 4 - ВТОРОЙ ФРОНТЕНД (экран задач)
=========================================================
Проект: todo-приложение (фронт на TypeScript + бэк на Kotlin + база PostgreSQL).
Твоя часть: frontend/src/pages/TasksPage.tsx, frontend/src/components/*
и frontend/src/styles.css.

Ссылка на репозиторий: https://github.com/dodry-question/todo-app-ts
(если ссылка другая - поменяй её в командах ниже)

---------------------------------------------------------
1. ЧТО СКАЧАТЬ
---------------------------------------------------------
1) Node.js LTS (вместе с npm) ...... https://nodejs.org
2) Git ............................. https://git-scm.com/download/win
3) Редактор кода (например, VS Code) ... https://code.visualstudio.com

Больше ничего не нужно.

---------------------------------------------------------
2. ПРОВЕРИТЬ, ЧТО ВСЁ ВСТАЛО
---------------------------------------------------------
Открой PowerShell и выполни по очереди:

   node -v
   npm -v
   git --version

Все три команды должны показать версию, а не ошибку.

---------------------------------------------------------
3. ЗАБРАТЬ ПРОЕКТ И СОЗДАТЬ СВОЮ ВЕТКУ
---------------------------------------------------------
   git clone https://github.com/dodry-question/todo-app-ts
   cd todo-app-ts/frontend
   git checkout -b frontend-tasks

(в ветке main напрямую не работаем)

---------------------------------------------------------
4. УСТАНОВИТЬ ЗАВИСИМОСТИ (делается один раз)
---------------------------------------------------------
Из папки frontend:

   npm install react react-dom react-router-dom

   npm install -D vite @vitejs/plugin-react typescript @types/react @types/react-dom @types/node

Папка node_modules появится сама, в git она не попадает.

---------------------------------------------------------
5. ЗАПУСТИТЬ ФРОНТ У СЕБЯ
---------------------------------------------------------
   npm run dev

Адрес откроется в выводе команды (обычно http://localhost:5173).
Скрипты запуска в package.json добавляет участник 1 - этот файл ты не трогаешь.

---------------------------------------------------------
6. ТВОИ ФАЙЛЫ (только их и правишь)
---------------------------------------------------------
   frontend/src/pages/TasksPage.tsx
   frontend/src/components/TaskForm.tsx
   frontend/src/components/TaskList.tsx
   frontend/src/components/TaskItem.tsx
   frontend/src/components/EditTaskModal.tsx
   frontend/src/styles.css

Полный список задач с галочками: файл docs/plan.md, раздел "Участник 4".

---------------------------------------------------------
7. ЧУЖИЕ ФАЙЛЫ НЕ ТРОГАЕМ
---------------------------------------------------------
Папка backend/, docs/, docker-compose.yml, а также frontend/src/App.tsx,
api.ts, auth.tsx, types.ts и страницы входа/регистрации - это участники 1, 2 и Миша.
Нужно что-то поменять в чужом файле - напиши владельцу, он поправит.

---------------------------------------------------------
8. ОТПРАВИТЬ РАБОТУ
---------------------------------------------------------
Когда что-то сделал:

   git pull
   git add .
   git commit -m "фронт: экран задач"
   git push -u origin frontend-tasks

Потом на GitHub нажать "Compare & pull request" и влить ветку в main.
